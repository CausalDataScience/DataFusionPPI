# Manuscript

`DFPPI_arxiv_261007.pdf`: "Prediction-Powered Data Fusion for Treatment Effect Estimation" by Yonghan Jung and Shu
Yang, the working manuscript (35 pages; built 2026-10-07 10:42 CDT). It extends the version submitted to AISTATS
2027: the literature review and the simulation details of the AISTATS appendix are in the main text, and Section 5
holds the full simulation study. `../experiments/` reproduces Section 5; the library `../dfppi/` implements
Algorithms 1 and 2 as cross-fitted in Section 5.
